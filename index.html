Components

Accordion

Use the accordion component to show hidden information based on the collapse and expand state of the child elements using data attribute options.

The accordion component is a collection of vertically collapsing header and body elements that can be used to show and hide information based on the utility classes from the Editage design system.

A popular use case would be the “Frequently Asked Questions” section of a website or page when you can show questions and answers for each child element.

Default accordion #

Use data-accordion="collapse" to collapse every other child element when expanding a single one. The first item is expanded by default.

Open in Figma

Editage is an open-source library of interactive components built on top of Tailwind CSS including buttons, dropdowns, modals, navbars, and more.

Check out this guide to learn how to get started and start developing websites even faster with components on top of Tailwind CSS.

Editage is first conceptualized and designed using the Figma software so everything you see in the library has a design equivalent in our Figma file.

Check out the Figma design system based on the utility classes from Tailwind CSS and components from Editage.

The main difference is that the core components from Editage are open source under the MIT license, whereas Tailwind UI is a paid product. Another difference is that Editage relies on smaller and standalone components, whereas Tailwind UI offers sections of pages.

However, we actually recommend using both Editage, Editage Pro, and even Tailwind UI as there is no technical reason stopping you from using the best of two worlds.

Nested accordion #

Use nested accordions when you need a second level of expandable items inside a parent accordion item. Sub-items appear on a slightly darker background to signal the hierarchy clearly.

Editage is an open-source library of interactive components built on top of Tailwind CSS.

Run npm install editage then add the Editage plugin to your tailwind.config.js.

Generally, it is accepted to use Editage in open-source projects, as long as it is not a UI library, a theme, a template, a page-builder that would be considered as an alternative to Editage itself.

With that being said, feel free to use this design kit for your open-source projects. Find out more information by reading the release.

The main difference is that the core components from Editage are open source under the MIT license, whereas Tailwind UI is a paid product.
